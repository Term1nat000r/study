# 🧠 База знаний:

Привет! Это репозиторий с моими конспектами и материалами для подготовки. 

Я использую «двухсторонний» подход к организации знаний: здесь есть как графовая структура связанных между собой Markdown-заметок, так и полная PDF-версия, где все материалы собраны в единую, последовательную книгу. Зачем из книги делать книгу? В моей версии я оставил только выжимку и возможно добавил, что-то близкое и нужное по тематике. Выбор нужного разумеется субъективен.

## 🗂 Что внутри?

Репозиторий разбит на каталоги по конкретным темам. Внутри каждого из них ты найдешь:

* **🕸 Связанные Markdown-заметки:** Набор `.md` файлов, объединенных перекрестными ссылками. Это полноценная база знаний, где концепции ссылаются друг на друга.
* **📕 Книга конспектов (PDF):** Зачем собирать книгу из конспектов? Это полная сборка всех материалов, аккуратно объединенная в один файл и выстроенная в строгом хронологическом порядке. Читается как единый учебник от первой до последней темы.
* **🎓 Экзаменационные билеты:** Списки вопросов для самопроверки и подготовки по конкретным блокам.

## 🛠 Как этим пользоваться?

**Настоятельно рекомендую открывать этот репозиторий через [Obsidian](https://obsidian.md/)**. 

Поскольку все `.md` файлы имеют двунаправленные связи (links), именно в Obsidian ты сможешь увидеть граф знаний, легко перемещаться по сложным структурам алгоритмов и использовать этот репозиторий на 100%.

## 🎯 Предложение по формату изучения

Наличие билетов в каждом разделе здесь не просто так. Я предлагаю следующий формат освоения:
1. Читаем темы в **PDF** для последовательного, хронологического погружения в предмет.
2. Используем `.md` файлы в Obsidian для быстрой навигации по конкретным концепциям и разбора связей между ними.
3. **Сдаем экзамен:** берем билеты из каталога и проводим срез знаний строго по пройденной теме, прежде чем двигаться к следующей.
