# 🧠 База знаний: [Название предмета, например: Алгоритмы и Машинное обучение]

Привет! Это репозиторий с моими конспектами и материалами для подготовки. 

Я использую «двухсторонний» подход к изучению тем: здесь есть как детальные, связанные между собой заметки для глубокого погружения, так и сжатая PDF-версия для быстрого обзора архитектуры предмета.

## 🗂 Что внутри?

Репозиторий разбит на каталоги по конкретным темам. Внутри каждого из них ты найдешь:

* **🕸 Связанные Markdown-заметки:** Набор `.md` файлов, объединенных перекрестными ссылками. Это не просто линейный текст, а полноценная база знаний, где концепции ссылаются друг на друга.
* **📕 PDF-выжимка (Книга конспектов):** Зачем собирать книгу из конспектов? Я взял все материалы, убрал абсолютно всю «воду», оставил только самую суть и добавил немного дополнительной, полезной информации по темам. Идеально для быстрого повторения.
* **🎓 Экзаменационные билеты:** Списки вопросов для самопроверки и подготовки. 

## 🛠 Как этим пользоваться?

**Настоятельно рекомендую открывать этот репозиторий через [Obsidian](https://obsidian.md/)**. 

Поскольку все `.md` файлы имеют двунаправленные связи (links), именно в Obsidian ты сможешь увидеть граф знаний, легко перемещаться между связанными концепциями и использовать этот репозиторий на 100%.

## 🎯 Предложение по формату изучения

Наличие билетов в каждом разделе здесь не просто так. Я предлагаю следующий формат освоения:
1. Читаем PDF для понимания общей картины (overview).
2. Изучаем `.md` файлы в каталоге для разбора деталей реализации.
3. **Сдаем экзамен:** берем билеты из каталога и проводим срез знаний строго по пройденной теме, прежде чем двигаться к следующей.
